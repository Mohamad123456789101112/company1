## 🔐 عزل الإعدادات و SQL

- كل بيانات الربط (Supabase + Google Auth + الأسرار) في ملف واحد محمي: **`config/platform.config.ts`**، يقرأ القيم من متغيرات البيئة فقط (لا مفاتيح في Git).
- **لا توجد أي صفحة في لوحة تحكم الأدمن تعرض ملف SQL أو المفاتيح.** صفحة «دليل التشغيل و SQL» حُذفت واستُبدلت بصفحة «حالة الحماية والربط» التي تعرض «جاهز/ناقص» فقط.
- تنفيذ السكيما من سطر الأوامر: `npm run db:setup` / الفحص: `npm run db:check`.
- الـ proxy يحجب `/config`, `/supabase`, `/scripts`, `/.env`, `/.git` تمامًا.

## 🚀 التشغيل السريع

```bash
cp .env.example .env.local     # ضع DATABASE_URL وغيره
npm install
npm run db:setup               # ينفّذ supabase/schema.sql
npm run dev
```

حساب المدير الافتراضي: `admin@mohamedfawzi.com` / `Admin@12345` — غيّره فور أول دخول.
تفاصيل Vercel و Google OAuth في [`docs/SETUP.md`](./docs/SETUP.md).

## 🎬 الفيديوهات بصفر تكلفة

- ارفع الشرح على يوتيوب **Unlisted** والصق الرابط، والمنصة تجلب العنوان والمدة والصورة تلقائيًا.
- قاعدة البيانات تخزّن **الرابط فقط**، والرابط الحقيقي لا يظهر في HTML ويعمل بتوكن موقّع مؤقت للطالب المشترك فقط.
- مشغّل `youtube-nocookie` مع علامة مائية باسم الطالب ومنع الفيديوهات المقترحة.

## 🛡️ الأمان

حد محاولات الدخول لكل حساب/IP + قفل تلقائي، bcrypt (cost 12)، جلسات SHA-256 في قاعدة البيانات بحد أقصى للأجهزة، Google OAuth مع PKCE، تحقق Zod، استعلامات مُعاملة، عمليات ذرّية للمحفظة والأكواد، RLS على كل جداول Supabase، سجل تدقيق كامل، ورؤوس CSP/HSTS/anti-clickjacking (مخففة فقط في بيئة المعاينة عبر `PREVIEW_EMBED=1`).
