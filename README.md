# منصة البشمهندس محمد فوزي للفيزياء ⚛️

منصة تعليمية متكاملة (LMS) للبشمهندس محمد فوزي – مدرس الفيزياء للمرحلة الثانوية (قناة Eng:mohamed fawzi على يوتيوب)، مبنية بـ **Next.js 16 + PostgreSQL (Supabase) + Drizzle ORM**، جاهزة للرفع على **Vercel** خلال دقائق.

## ✨ ما بداخل المنصة

| للطالب | للمدرس / الإدارة |
| --- | --- |
| صفحة رئيسية احترافية (هيرو، إحصائيات، صفوف، كورسات، مميزات، آراء، أسئلة شائعة، تواصل) | لوحة تحكم بإحصائيات حية |
| تسجيل / دخول بالبريد أو Google | إدارة الطلاب (حظر، إيقاف، رصيد، كلمة مرور، أدوار، تفعيل كورسات) |
| كورسات حسب الصف (1، 2، 3 ثانوي) مع حصص مجانية للمعاينة | إنشاء كورسات ← وحدات ← دروس (فيديو YouTube/Vimeo/Bunny/Drive، PDF، اختبار) |
| مشغّل دروس بعلامة مائية بهوية الطالب | محرر امتحانات وأسئلة اختيار من متعدد مع شرح الإجابة |
| امتحانات إلكترونية مؤقتة بتصحيح فوري | توليد أكواد شحن / تفعيل كورس بالجملة (للمكتبات) |
| محفظة: شحن بكود أو تحويل (فودافون كاش / إنستاباي) | مراجعة طلبات الدفع بضغطة (تأكيد = شحن تلقائي) |
| متابعة التقدم، نتائج الامتحانات، الإعلانات | إعلانات لصف محدد أو للجميع، رسائل التواصل |
| إدارة الأجهزة المتصلة وكلمة المرور | إعدادات المنصة بالكامل + سجل الأمان + صفحة الحماية والتشغيل |

## 🆕 التحديث الشامل (الأخير)

- **مقاسات متجاوبة مضبوطة:** الصفحة الرئيسية بعرض 80% على التابلت، صفحة تسجيل الدخول (الصندوق + الصورة) بعرض 90%، ولوحتا التحكم (الأدمن والطالب) بعرض 90% لعرض الجداول والرسوم بالكامل بدون سكرول جانبي.
- **تبديل الثيم فوري (< 10 ملّي ثانية):** Local Storage + Class على `<html>` مع تطبيق الثيم قبل أول رسم للصفحة.
- **آراء الطلاب:** كروت تنزلق بسلاسة من اليمين إلى اليسار مباشرة على خلفية الموقع الأصلية بدون صندوق طافي.
- **لوحة أدمن خطوة بخطوة:** دليل مبسّط يناسب أي مدرس + **ترتيب المنهج بالسحب والإسقاط** (كورس ← فصول ← دروس، وسحب الدروس بين الفصول).
- **جلب بيانات يوتيوب تلقائيًا:** بمجرد لصق الرابط يُجلب اسم الدرس والمدة والصورة المصغّرة تلقائيًا.
- **توليد الامتحانات بالذكاء الاصطناعي:** قالب JSON جاهز تنسخه لـ ChatGPT أو Gemini والصق الناتج ليُنشأ الامتحان بالكامل بالتصحيح التلقائي في ثوانٍ.
- **إحصائيات دقيقة:** إجمالي الطلاب، المبيعات، تفعيلات الأكواد، أكثر الكورسات مشاهدة واشتراكًا + رسوم بيانية للإيرادات والتسجيلات.
- **لوحة الطالب التفاعلية:** نسبة التقدم، متوسط وتطور درجات الامتحانات، النشاط الأسبوعي، وأوسمة التميز.
- **عزل الإعدادات الحساسة:** Google Auth وأكواد SQL الخاصة بـ Supabase في Config محمي (`src/lib/secure-config.ts` + `.env`) – **ممنوع ظهورها أو فتحها داخل لوحة التحكم نهائيًا**.
- **وضع العرض التجريبي:** بدون `DATABASE_URL` يعمل الموقع كاملًا على قاعدة بيانات مدمجة (PGlite) – اضبط `DATABASE_URL` للانتقال لـ Supabase مباشرة.

## 🎬 الفيديوهات بصفر تكلفة (YouTube Unlisted + Supabase)

- المستر يرفع الشرح على قناته بحالة **غير مدرج (Unlisted)** ويلصق الرابط في خانة «رابط الفيديو من يوتيوب» عند إضافة الدرس.
- Supabase تخزّن **الرابط فقط** (بضعة بايتات) – لا فيديوهات في قاعدة البيانات، فالباقة المجانية تكفي لآلاف الطلاب والكورسات.
- صفحة الدرس تتحقق أولًا من الاشتراك/كود السنتر، ثم يحصل المشغّل على رابط التضمين عبر توكن موقّع مؤقت من الخادم (`/api/media/<token>`) – الرابط الحقيقي لا يظهر في HTML ولا يعمل لحساب آخر.
- المشغّل داخل المنصة: `youtube-nocookie`، بدون فيديوهات مقترحة، حجب النقر على شعار/عنوان يوتيوب، علامة مائية ديناميكية باسم ورقم الطالب، وإيقاف العرض عند الخروج من التبويب.
- عند النمو يمكن الانتقال إلى **Bunny Stream** (رفع من الجهاز + روابط موقّعة) من لوحة الإدارة → إعدادات الفيديو دون أي تغيير في الكود.

## 🔐 الأمان (Hardened)

- حد أقصى لمحاولات الدخول **لكل حساب (5)** و**لكل IP (20)** كل 15 دقيقة + قفل الحساب تلقائيًا (Brute-force protection) – مخزن في قاعدة البيانات فيعمل على كل سيرفرات Vercel.
- كلمات المرور bcrypt (cost 12) مع معادلة توقيت ضد تخمين الحسابات.
- جلسات مخزنة في قاعدة البيانات (SHA-256) مع حد للأجهزة، وكوكيز `HttpOnly + Secure + SameSite`.
- Google OAuth 2.0 مع **PKCE** و`state` ضد CSRF.
- رؤوس أمان كاملة: CSP, HSTS, X-Frame-Options, nosniff, Referrer-Policy, Permissions-Policy.
- تحقق من كل المدخلات بـ Zod، استعلامات مُعاملة (لا SQL Injection)، حماية من Open Redirect وIDOR.
- عمليات المحفظة والأكواد ذرّية (لا إنفاق مزدوج / لا استخدام مزدوج للكود).
- تفعيل **Row Level Security** على كل جداول Supabase لمنع الوصول عبر REST API بالمفتاح العام.
- سجل تدقيق كامل لكل الأحداث الحساسة.

## 🚀 التشغيل في 3 خطوات

### 1) Supabase
1. أنشئ مشروعًا على [supabase.com](https://supabase.com).
2. افتح **SQL Editor** والصق محتوى الملف [`supabase/schema.sql`](./supabase/schema.sql) ← **Run**.
3. من **Project Settings → Database → Connection string (URI)** انسخ رابط الاتصال (Session pooler – port 5432).

### 2) Vercel
1. ارفع المشروع على GitHub ثم استورده في [vercel.com](https://vercel.com).
2. أضف متغيرات البيئة (انظر [`.env.example`](./.env.example)):
   - `DATABASE_URL` – رابط Supabase (أو فعّل تكامل Supabase في Vercel؛ التطبيق يستخدم `POSTGRES_URL` الذي يوفّره التكامل تلقائيًا)
   - `NEXT_PUBLIC_APP_URL` – رابط موقعك `https://...`
   - `ADMIN_EMAILS` – بريدك (يُرقّى لمدير تلقائيًا)
   - `GOOGLE_CLIENT_ID` و `GOOGLE_CLIENT_SECRET` (الخطوة 3)
   - `MEDIA_SIGNING_SECRET` – نص عشوائي طويل لتوقيع روابط الفيديو/PDF المؤقتة
   - `BUNNY_TOKEN_AUTH_KEY` (اختياري) – مفتاح Token Authentication من Bunny Stream
3. **Deploy**.

### 3) Google Login
1. [Google Cloud Console](https://console.cloud.google.com) → **APIs & Services → Credentials → Create OAuth client ID** (Web application).
2. أضف في **Authorized redirect URIs**: `https://your-domain.vercel.app/api/auth/google/callback`
3. ضع Client ID / Secret في متغيرات Vercel وأعد النشر.

> حساب المدير الافتراضي من ملف SQL: `admin@mohamedfawzi.com` / `Admin@12345` — **غيّر كلمة المرور فور أول دخول** (سيُطلب منك ذلك).

## 🧪 تشغيل محلي

```bash
npm install
cp .env.example .env   # وعدّل DATABASE_URL
npx drizzle-kit push    # أو نفّذ supabase/schema.sql
npm run dev
```

المنصة تبدأ **فارغة تمامًا** (بدون أي بيانات وهمية): سجّل دخول المدير → اضبط الإعدادات (أرقام التواصل، فودافون كاش، الباقات) → أضف الكورسات والدروس والامتحانات من لوحة الإدارة.

## 🗂️ البنية

```
src/
  actions/      Server Actions (auth, student, admin)
  app/          الصفحات (الرئيسية، الكورسات، لوحة الطالب، المشغّل، الامتحانات، الإدارة)
  components/   مكونات الواجهة
  db/           مخطط Drizzle
  lib/          المصادقة، الحد من الطلبات، الأمان، التحقق، الإعدادات
  proxy.ts      حماية المسارات الخاصة
supabase/schema.sql   ← الملف الذي تلصقه في Supabase
```
