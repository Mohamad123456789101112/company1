## 3) لوحة تحكم الأدمن — بسيطة وشاملة

- **دليل «ابدأ من هنا» بـ 4 خطوات** أعلى لوحة التحكم في صورة كروت مرتبة تشرح للمدرس غير التقني المسار كاملًا.
- **السحب والإسقاط للمنهج** (كورس ← فصول ← دروس):
  - مكوّن جديد `src/components/admin/curriculum-dnd.tsx` + إجراء خادم `reorderCurriculumAction` مع تحقق كامل أن كل فصل/درس يخص نفس الكورس (حماية من التلاعب).
  - مقبض ⠿ لكل فصل ودرس، إمكانية نقل درس إلى فصل آخر، أزرار ▲▼ لمن يستخدم الكيبورد، وشريط «حفظ الترتيب» يظهر عند وجود تغييرات + إمكانية التراجع.
- **جلب بيانات يوتيوب تلقائيًا:** بمجرد لصق الرابط:
  - العنوان ← يُملأ في خانة «عنوان الدرس».
  - المدة بالدقائق ← تُملأ في خانة «المدة».
  - الصورة المصغرة + القناة + معاينة فورية.
  - المصدر: YouTube oEmbed + صفحة المشغل (بدون مفاتيح API)، وإجراء الخادم في `src/actions/youtube.ts`.
- **مولّد الامتحانات بالذكاء الاصطناعي (JSON):**
  - قالب جاهز + برومبت جاهز للنسخ إلى ChatGPT/Gemini.
  - لصق JSON مباشرة أو رفع ملف `.json`.
  - يقبل أشكال الإجابات: `correctIndex` (0-based)، `correct: "أ/ب/ج/د"`، أو نص الاختيار.
  - وضعان: إنشاء امتحان جديد كامل داخل كورس، أو إضافة أسئلة لامتحان قائم.
  - الملفات: `src/actions/admin.ts` (`importQuizJsonAction`) + `AiQuizImportForm` في `src/components/admin/forms.tsx`، ومتاح في صفحة الامتحانات وفي صفحة كل امتحان.
- **إحصائيات دقيقة:** إجمالي الطلاب، إيرادات 30 يوم والإجمالي، طلبات الدفع المعلّقة، اشتراكات الأسبوع، حالة الأكواد (متاح/مستخدم)، **أكثر الكورسات اشتراكًا**، و**أكثر الكورسات مشاهدة** (حسب الدروس المكتملة).
- حذف صفحة «دليل التشغيل و SQL» نهائيًا من لوحة التحكم واستبدالها بصفحة **حالة الحماية والربط** التي تعرض «جاهز/ناقص» فقط.

## 5) الحماية وعزل ملفات الربط و SQL

| الإجراء | التفاصيل |
| --- | --- |
| ملف إعدادات فريد ومحمي | `config/platform.config.ts` — يحتوي هيكل إعدادات Supabase و Google Auth والأسرار، ويقرأ القيم من متغيرات البيئة فقط (لا مفاتيح داخل Git). |
| server-only | `src/lib/config.ts` يعيد التصدير مع `import "server-only"` ⇒ لا يمكن استيراده في أي كود يعمل بالمتصفح. |
| خارج لوحة التحكم | حُذفت صفحة `/admin/setup` بالكامل، ولا توجد أي واجهة تعرض ملف SQL أو متغيرات البيئة أو رابط قاعدة البيانات. |
| تنفيذ SQL خارج الويب | `scripts/db-setup.mjs` عبر `npm run db:setup` من سطر الأوامر، و`npm run db:check` للتحقق. |
| حجب المسارات | الـ proxy يرفض `/config`, `/supabase`, `/scripts`, `/.env`, `/.git` (404). |
| التوثيق | `docs/SETUP.md` داخل المستودع فقط. |
| تعزيز إضافي | كل قراءات Google/DB/ADMIN_EMAILS تمر عبر ملف الإعدادات الموحّد. |

## 8) خطوات النشر النهائية (لمرة واحدة)

1. أنشئ مشروع Supabase ونفّذ `npm run db:setup` محليًا (أو الصق `supabase/schema.sql` مرة واحدة في SQL Editor — اختياري).
2. استورد المستودع في Vercel وأضف متغيرات البيئة (انظر `.env.example` و`docs/SETUP.md`).
3. فعّل Google OAuth مع Redirect URI: `https://<domain>/api/auth/google/callback`.
4. غيّر كلمة مرور المدير الافتراضية فور أول دخول.
5. ارفع صور المدرس الحقيقية من **الإدارة → المظهر → صور الموقع**.
